
## Project Description
I'm looking for an undergrad or two to help automate some aspects of my RELAP workflow using Python. This is a relatively short-term project which will help me run sensitivity studies on my MSRE model, something that I'm hoping to complete this semester. 

The undergrads would be writing a Python code which can automatically scale certain parameters in the RELAP model and generate a new input file (a basic text file). Most of this will be achieved through string manipulation (the entire RELAP input file is treated as a very large f-string). The python code will search the relap file string for specific terms and replace these with the user defined parameters. Since there are maybe 50 separate components in the RELAP model, this automation would save an immense amount of time.
